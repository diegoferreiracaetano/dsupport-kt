A customer support assistant with several AI agents, built by hand in Kotlin Multiplatform, explained step by step.Um assistente de suporte com vários agentes de IA, construído à mão em Kotlin Multiplatform, explicado passo a passo.

Customers ask about orders, returns and policies. Most questions can be answered from a help center or an order system, and a few need a person. The goal: answer the first group, hand the second to a human, and never invent a fact. No agent framework was used, so every concept is visible in the code.Clientes perguntam sobre pedidos, devoluções e políticas. A maioria pode ser respondida por uma central de ajuda ou um sistema de pedidos, e algumas precisam de uma pessoa. O objetivo: responder o primeiro grupo, passar o segundo a um humano e nunca inventar um fato. Nenhum framework de agentes foi usado, então cada conceito aparece no código.

Real code from the repositoryCódigo real do repositório etapa-6
class SubAgentTool(
    private val name: String,
    description: String,
    private val newAgent: () -> Agent,
) : Tool {

    override val spec = ToolSpec(name, description, stringSchema("task"))

    override suspend fun run(args: JsonObject): ToolResult {
        val task = args.stringArg("task") ?: return fail("missing_argument:task")
        return try {
            ToolResult(newAgent().run(task))
        } catch (e: CancellationException) {
            throw e
        } catch (e: Exception) {
            ToolResult("error: specialist '$name' failed: ${e.message}", isError = true)
        }
    }
}

fun subAgentTool(name: String, description: String, newAgent: () -> Agent): Tool = SubAgentTool(name, description, newAgent)
